## 2. Resumo Executivo & Contexto de Negócio

O documento descreve a operação de modificação das informações previamente registradas para um Broker de Seguros e Resseguros. A operação também permite inabilitar o Broker no sistema.

A inabilitação indica que o Broker não deve ser empregado, contemplado ou considerado nos processos operacionais da entidade. Quando o Broker estiver inabilitado, deve ser registrada uma causa de inabilitação definida no catálogo mestre do sistema para a atividade do terceiro.

O conteúdo detalha atributos cadastrais relacionados à identificação, origem, tipologia, tributação e plano de pagamento do Broker. A sequência de captura dos atributos é apresentada como leitura da esquerda para a direita e de cima para baixo dentro do bloco de informação.

O documento está associado à documentação Reef e menciona a entidade MAPFRE no contexto da retenção de impostos aplicada às operações econômicas com o Broker.

## 4. Regras de Negócio, Especificações Funcionais & Processos

### 4.1 Operação disponível

A operação permite duas ações possíveis:

1. **Modificar** informações previamente cadastradas do Broker de Seguros e Resseguros.
2. **Inabilitar** o Broker de Seguros e Resseguros.

### 4.2 Sequência de captura

Os atributos do bloco de informação devem ser capturados na sequência visual apresentada no formulário:

- Da esquerda para a direita.
- De cima para baixo.

### 4.3 Regras para inabilitação do Broker

- O atributo **Inhabilitación** informa ao sistema que o Broker está inabilitado.
- Um Broker inabilitado não deve ser empregado, contemplado ou considerado nos processos operacionais da entidade.
- Caso o Broker esteja inabilitado, o atributo **Causa de Inhabilitación** deve conter o código de uma causa de inabilitação.
- A causa de inabilitação deve estar definida no catálogo mestre do sistema para a atividade do terceiro.

### 4.4 Regras de classificação do Broker

A **Tipología del Broker** classifica o Broker segundo duas dimensões:

- Local ou estrangeiro.
- Afiliado ou não afiliado localmente.

Quando o idioma da definição for espanhol, são apresentados os seguintes valores:

| Código | Valor apresentado |
| :--- | :--- |
| AL | Afiliado (Local) |
| NL | No Afiliado (Local) |
| AE | Afiliado (Extranjera) |
| NE | No Afiliado (Extranjera) |

### 4.5 Regras tributárias e econômicas

- O **Código de Impuesto sobre la Renta** contém o código do imposto que a entidade MAPFRE aplicará como retenção nas operações econômicas com o Broker de Seguros e Resseguros.
- O **Impuesto sobre Intereses de los Depósitos de Reaseguro** contém o código de imposto aplicado ao Broker sobre juros gerados por depósitos de resseguro.
- O **Plan de Pago** identifica a periodicidade a ser considerada no contato com o Broker e no envio de informações econômicas. São citados como exemplos: anual, semestral, trimestral e mensal.

## 6. Bateria de Perguntas & Respostas para RAG (FAQ Sintético)

### P1: Quais ações estão disponíveis para o cadastro de um Broker de Seguros e Resseguros?
**R:** A operação disponibiliza as ações **MODIFICAR** e **INHABILITAR**. MODIFICAR permite alterar informações previamente registradas do Broker, enquanto INHABILITAR marca o Broker como não utilizável nos processos operacionais da entidade.

### P2: O que acontece quando um Broker é marcado como inabilitado?
**R:** O atributo **Inhabilitación** indica ao sistema que o Broker está inabilitado. Nessa condição, o Broker não deve ser empregado, contemplado ou considerado nos processos operacionais da entidade.

### P3: Quando a causa de inabilitação deve ser informada?
**R:** A **Causa de Inhabilitación** deve ser informada quando o Broker de Seguros e Resseguros estiver inabilitado. Esse atributo contém o código de uma causa definida no catálogo mestre do sistema para a atividade do terceiro.

### P4: De onde deve vir o código da causa de inabilitação?
**R:** O código deve corresponder a uma causa de inabilitação definida no catálogo mestre do sistema para a atividade do terceiro.

### P5: Qual é a sequência de preenchimento dos atributos do bloco de informação?
**R:** O documento determina que os atributos devem ser capturados da esquerda para a direita e de cima para baixo.

### P6: O que representa o campo “Nombre Corto del Broker”?
**R:** O campo contém o nome abreviado do Broker de Seguros e Resseguros. O documento informa que esse nome abreviado já terá sido capturado no bloco de informação.

### P7: Como a tipologia do Broker é classificada?
**R:** A **Tipología del Broker** determina se o Broker é local ou estrangeiro e se está ou não afiliado localmente. Para definições em espanhol, os valores apresentados são AL, NL, AE e NE.

### P8: Qual é o significado do código AL na tipologia do Broker?
**R:** O código **AL** significa **Afiliado (Local)**, conforme os valores apresentados para definições em espanhol.

### P9: Para que serve o “Código de Impuesto sobre la Renta”?
**R:** Esse dado contém o código do imposto que a entidade MAPFRE aplicará como retenção nas operações econômicas com o Broker de Seguros e Resseguros.

### P10: Qual imposto está relacionado aos juros de depósitos de resseguro?
**R:** O atributo **Impuesto sobre Intereses de los Depósitos de Reaseguro** contém o código de imposto aplicado ao Broker sobre os juros gerados pelos depósitos de resseguro.

### P11: O que o Plano de Pagamento controla no relacionamento com o Broker?
**R:** O **Plan de Pago** identifica a temporalidade a ser considerada no contato com o Broker e no envio de informações econômicas. O documento cita periodicidades anual, semestral, trimestral e mensal como exemplos.

### P12: O documento especifica APIs ou métodos HTTP para alteração do Broker?
