## 2. Resumo Executivo & Contexto de Negócio

O documento define a classificação dos formatos utilizados para cheques e transferências. O objetivo declarado é estabelecer propriedades que permitam identificar e diferenciar esses formatos.

Cada formato possui uma chave de identificação, uma nomenclatura associada e um tipo. O tipo determina se o formato é aplicável a cheques ou a transferências.

Para formatos classificados como cheques, o documento apresenta a propriedade adicional **Cheque manual**. Essa propriedade determina se o formato será utilizado para cheques manuais.

O conteúdo não descreve integrações, contratos de API, regras de persistência, ambientes, permissões ou fluxos operacionais detalhados.

## 4. Regras de Negócio, Especificações Funcionais & Processos

1. Um formato deve possuir uma **chave** que o identifique.
2. Um formato deve possuir um **nome**, definido como a nomenclatura associada à chave do formato.
3. Um formato deve possuir um **tipo de formato**.
4. O tipo de formato identifica se o formato se aplica a:
   - **Cheques**, identificado pela classificação `(CH)`.
   - **Transferências**, identificado pela classificação `(TR)`.
5. Quando um formato for destinado a cheques, a propriedade **Cheque manual** determina se o formato será utilizado para cheques manuais.
6. O documento não especifica valores permitidos, formato de preenchimento, obrigatoriedade, validações ou comportamento padrão para a propriedade **Cheque manual**.
