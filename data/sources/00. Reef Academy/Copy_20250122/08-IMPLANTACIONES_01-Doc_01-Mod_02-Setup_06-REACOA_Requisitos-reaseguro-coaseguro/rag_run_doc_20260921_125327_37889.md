## 2. Resumo Executivo & Contexto de Negócio

O documento descreve os requisitos de negócio que devem ser coletados para configurar os módulos de **Resseguro** e **Cosseguro** no Core REEF. A abordagem indicada consiste em partir dos requisitos de negócio já existentes no país.

Para o módulo de Resseguro, a configuração deve considerar aspectos como tipos de resseguro — proporcional e não proporcional —, fronting, comissões, depósitos e impostos. O documento menciona um formulário ou checklist destinado à coleta desses requisitos.

Para o módulo de Cosseguro, a configuração deve considerar os tipos de cosseguro, comissões e impostos existentes no país. Também é mencionado um formulário ou checklist específico para levantamento dos requisitos de cosseguro.

O conteúdo fornecido não detalha regras de cálculo, contratos, integrações, métodos HTTP, estruturas de dados, responsabilidades por equipe, ambientes ou etapas operacionais para preenchimento e processamento dos formulários.
