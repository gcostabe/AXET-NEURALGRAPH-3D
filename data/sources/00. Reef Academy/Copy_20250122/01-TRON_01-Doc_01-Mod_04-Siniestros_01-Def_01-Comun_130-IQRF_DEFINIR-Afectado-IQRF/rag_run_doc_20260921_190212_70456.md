## 2. Resumo Executivo & Contexto de Negócio

O documento define os possíveis afetados por uma IQRF, sigla apresentada como *Incidencia, Queja, Reclamación o Felicitaciones*. O objetivo declarado é estabelecer uma definição para todos os afetados associados a uma IQRF.

A definição de afetado possui propriedades gerais para identificação, idioma, descrição, vigência e condição de uso. A propriedade **chave do afetado** armazena a chave associada ao afetado de uma IQRF.

O documento também estabelece que a descrição do afetado possui um idioma associado e que existe uma data de validade para indicar quando a definição registrada entra em vigor. Há ainda o indicador **Inhabilitado?**, utilizado para informar se o registro está indisponível para uso.

Não há detalhamento adicional sobre sistemas integrados, contratos de API, métodos HTTP, persistência de dados, regras de validação, permissões, responsáveis pelo cadastro ou fluxo operacional de criação e manutenção dos afetados.

## 4. Regras de Negócio, Especificações Funcionais & Processos

### Objetivo funcional

A finalidade apresentada é definir todos os possíveis afetados por uma IQRF.

### Propriedades gerais da definição de afetado

1. **Chave do afetado**
   - Deve conter a chave do afetado da IQRF.

2. **Idioma**
   - Contém o idioma no qual está a descrição do afetado.

3. **Nome do afetado**
   - Contém a descrição do afetado.

4. **Data de validade**
   - Indica a data em que entra em vigor a definição do afetado registrado.

5. **Inhabilitado?**
   - Indica se o registro está inabilitado para ser utilizado ou não.

### Restrições e lacunas documentais

- O documento não define o formato da chave do afetado.
- O documento não informa valores permitidos para idioma.
- O documento não especifica formato, obrigatoriedade ou regras de preenchimento para nome, descrição ou data de validade.
- O documento não estabelece se o indicador **Inhabilitado?** é booleano, textual ou codificado.
- O documento não descreve regras para expiração, alteração, exclusão ou reativação de registros.
- O documento não detalha o exemplo apresentado após a propriedade **Fecha de validez**.

## 6. Bateria de Perguntas & Respostas para RAG (FAQ Sintético)

### P1: Qual é o objetivo do documento sobre afetados de IQRF?
**R:** O objetivo é definir todos os possíveis afetados por uma IQRF. O documento identifica IQRF como *Incidencia, Queja, Reclamación o Felicitaciones*.

### P2: O que representa a chave do afetado em uma IQRF?
**R:** A chave do afetado é uma propriedade que contém a chave associada ao afetado da IQRF. O documento não especifica seu formato, tamanho, origem ou regras de geração.

### P3: Para que serve o campo Idioma na definição de afetado?
**R:** O campo **Idioma** contém o idioma no qual está registrada a descrição do afetado. O documento não lista idiomas permitidos nem define códigos ou padrões de linguagem.

### P4: Qual informação é armazenada no campo Nome do afetado?
**R:** Segundo o documento, a propriedade **Nome do afetado** contém a descrição do afetado. Não há detalhamento sobre comprimento, obrigatoriedade, idioma padrão ou convenções de preenchimento.

### P5: O que a data de validade indica para um afetado?
**R:** A data de validade indica em qual data entra em vigor a definição do afetado registrada. O documento não informa se existe data de fim de vigência ou como tratar registros expirados.

### P6: O que significa o indicador Inhabilitado?
**R:** O indicador **Inhabilitado?** informa se o registro está inabilitado para ser utilizado ou não. O documento não define os valores técnicos do indicador, como `true/false`, `S/N` ou outra codificação.

### P7: O documento descreve APIs ou integrações para consultar afetados de IQRF?
**R:** Não. O documento não detalha APIs, endpoints, métodos HTTP, contratos JSON, sistemas consumidores, sistemas produtores ou mecanismos de integração relacionados aos afetados de IQRF.

### P8: Há regras para reativar um afetado inabilitado?
**R:** Não. O conteúdo apenas informa que o indicador **Inhabilitado?** determina se o registro pode ser usado. Não há regra documentada para reativação, aprovação, auditoria ou histórico de mudanças.

### P9: Quais são as propriedades gerais apresentadas para um afetado?
**R:** As propriedades gerais apresentadas são: chave do afetado, idioma, nome do afetado, data de validade e o indicador **Inhabilitado?**.
