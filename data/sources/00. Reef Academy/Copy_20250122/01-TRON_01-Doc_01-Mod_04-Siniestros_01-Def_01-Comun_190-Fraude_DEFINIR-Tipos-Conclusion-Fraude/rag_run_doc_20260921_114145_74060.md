## 4. Regras de Negócio, Especificações Funcionais & Processos

A definição de um tipo de conclusão do fraude contém as seguintes propriedades gerais:

1. **Código do Tipo de Conclusão do Fraude**
   - Contém a chave que identifica o tipo de conclusão do fraude.

2. **Idioma**
   - Contém o código do idioma no qual os textos estão definidos.

3. **Nome do Tipo de Conclusão do Fraude**
   - Contém a descrição do tipo de conclusão do fraude.

4. **Es Fraude?**
   - Indica se a conclusão é ou não fraude.

5. **Inhabilitado**
   - Indica se a definição está ou não habilitada para ser utilizada.

6. **Fecha de validez**
   - Contém a data em que a definição entra em vigor.

Não foram especificados formatos de código, valores permitidos, obrigatoriedade dos campos, regras de unicidade, comportamento para datas expiradas ou critérios para classificar uma conclusão como fraude.
