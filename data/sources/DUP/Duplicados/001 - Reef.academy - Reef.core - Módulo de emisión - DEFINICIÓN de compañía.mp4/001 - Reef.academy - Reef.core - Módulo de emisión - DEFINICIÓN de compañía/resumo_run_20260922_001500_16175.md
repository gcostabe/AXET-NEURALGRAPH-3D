### 4.1. Definição operacional apresentada

A companhia é o elemento que organiza e segmenta as informações dentro do sistema. A explicação afirma que o sistema está “distribuído” ou “seccionado” por companhia.

Em termos práticos, isso significa que:

- o sistema suporta mais de uma companhia;
- diferentes seguradoras podem coexistir em um mesmo ambiente;
- as informações são associadas a uma companhia específica;
- a companhia define o contexto em que produtos e demais configurações são utilizados.

### 4.2. Multicompanhia

O RIV foi descrito como um conceito de instalação em nuvem. Dentro de uma única instalação ou instância, podem coexistir várias companhias.

Essa coexistência pode ocorrer em dois cenários:

1. **Companhias do mesmo país**

A apresentação não detalha se cada companhia possui isolamento de dados em nível lógico, físico, de banco de dados ou de outro mecanismo técnico. O que fica explicitamente estabelecido é a separação funcional e de parametrização por companhia.

## 6. Solução ou direcionamento apresentado

O direcionamento apresentado é a operação do RIV com um modelo multicompanhia, no qual uma mesma instalação em nuvem pode hospedar mais de uma seguradora.

Cada companhia possui seu próprio conjunto de definições. Como consequência:

- uma companhia pode comercializar determinados produtos;
- outra companhia pode ter produtos diferentes;

A solução não é descrita como uma integração entre sistemas independentes, mas como uma capacidade nativa de segmentação dentro do próprio ambiente RIV.
